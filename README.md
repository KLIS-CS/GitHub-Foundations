## Recommended Order

**CP1 → CP2 → CP3 → CP4 → CP5**

The sequence moves from repository setup, through the core Git collaboration workflow, into task management and the local/remote mental model, and ends with one integrated mastery challenge.

## Student Start Flow

### CP1

CP1 intentionally starts differently because the skill being tested is **creating a repository from scratch**.

```text
Open CP1
→ Start CP1 / Create Repository
→ Configure README + .gitignore + LICENSE
→ Submit CP1 Issue Form
→ Automatic grading
→ Teacher grading
```

### CP2–CP5

These checkpoints use reusable exercise copies:

```text
Open checkpoint
→ Copy Exercise
→ Actions
→ Start Exercise
→ Clone locally
→ Complete required branch/work
→ Push
→ Open Pull Request
→ Automatic grading
→ Teacher grading
```

The student should leave the required Pull Request open until teacher review is complete.

## Grading Model

All five checkpoints use the same overall score structure:

```text
60 points — automatic evidence
40 points — teacher review
100 points — final score
```

The teacher grading area automatically provides a fixed rubric template. The teacher copies the template into a new comment, changes the category scores, adds feedback, and the workflow calculates the teacher subtotal and final score.

## Teacher Setup

- **CP1:** does not need to be a Template repository.
- **CP2–CP5:** enable **Settings → General → Template repository** so the **Copy Exercise** buttons work.
- CP2 must live at `KLIS-CS/GitHub-Feature-Branch-Pull-Request-Workflow` for the navigation and Copy Exercise link to resolve correctly.
