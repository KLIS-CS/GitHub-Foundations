# GitHub Foundations

A navigation hub for the KLIS-CS GitHub Foundations checkpoint quizzes.

## Checkpoint Navigation

| Checkpoint | Skill | Exercise Repository |
|---|---|---|
| **CP1** | Repository Setup | [GitHub-Repository-Setup](https://github.com/KLIS-CS/GitHub-Repository-Setup) |
| **CP2** | Feature Branch & Pull Request Workflow | [GitHub-Feature-Branch-Pull-Request-Workflow](https://github.com/KLIS-CS/GitHub-Feature-Branch-Pull-Request-Workflow) |
| **CP3** | Issues & Project Management | [GitHub-Issues-Projects-Workflow](https://github.com/KLIS-CS/GitHub-Issues-Projects-Workflow) |
| **CP4** | Local ↔ Remote Mental Model | [KLIS-CS-Git-Local-Remote-Workflow](https://github.com/KLIS-CS/KLIS-CS-Git-Local-Remote-Workflow) |
| **CP5** | Final Integrated Challenge | [GitHub-Final-Integrated-Challenge](https://github.com/KLIS-CS/GitHub-Final-Integrated-Challenge) |

## Recommended Order

**CP1 → CP2 → CP3 → CP4 → CP5**

The sequence moves from repository setup, through the core Git collaboration workflow, into task management and the local/remote mental model, and ends with one integrated mastery challenge.

## Student Rule

Open only the checkpoint you are currently assigned. Use the exercise repository's README, create the required feature/checkpoint branch, complete the work locally, push it, and submit the required Pull Request. Do not work directly on `main`.

## Teacher Setup

Each checkpoint repository should be configured as a **Template repository** in GitHub repository settings so students can create their own exercise copy.
